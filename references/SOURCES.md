# Project Rules

Claude must follow these rules throughout the project.

- Never invent DGA requirements.
- Every major design decision should reference one or more sources above.
- If a requirement cannot be verified, mark it as "Needs Confirmation."
- Prefer official DGA guidance over community examples.
- Build the Financial Academy page using official DGA patterns whenever possible.
- Keep the project Arabic-first with RTL support.
- Design for WCAG 2.2 AA accessibility.
- Favor reusable components over page-specific implementations.
- Produce planning documents before implementation.
