# Arabic Version

**الواجهة:** بوابة المدرب

---

### نطاق الرحلة

تبدأ من لحظة إرسال الاتفاقية المعتمدة داخليًا بالكامل تلقائيًا للمتقدم (من J-10). تغطي وصول المتقدم للاتفاقية ببوابته، واتخاذه أحد ثلاثة قرارات: توقيع إلكتروني (اعتماد)، رفض، أو طلب تعديل. تنتهي بتوقيع المتقدم — تفعيل الاتفاقية، توليد ملف PDF نهائي موقَّع، وحفظ نسخة بالنظام الداخلي وبوابة المدرب معًا. إنشاء ملف المدرب نفسه يُغطى برحلة لاحقة (CAP-04).

---

### رحلة المستخدم

١. المتقدم يستلم إشعارًا بوصول الاتفاقية المعتمدة داخليًا بالكامل (من J-10)
٢. يجدها ضمن "إدارة الطلبات" ببوابة المدرب
٣. يعاين الاتفاقية أو يحمّلها بالكامل قبل اتخاذ قراره
٤. يتخذ أحد ثلاثة قرارات: توقيع إلكتروني واعتماد، رفض، أو طلب تعديل
٥. عند التوقيع، تتحوَّل حالته تلقائيًا إلى "معتمد"، ويُولَّد ملف PDF نهائي موقَّع، وتصبح الاتفاقية نشطة
٦. عند الرفض، يُغلق الطلب نهائيًا
٧. عند طلب التعديل، تعود الملاحظة لصاحب الطلب (من J-10)، الذي يعدّل الاتفاقية ويعيد إرسالها عبر سير توقيع داخلي جديد بالكامل

---

### الخصائص الرئيسية والوظائف

**F1. قرار المتقدم على الاتفاقية**
الوصف: المتقدم يجد اتفاقيته المعتمدة داخليًا بالكامل ضمن بوابته، ويتخذ أحد ثلاثة قرارات: توقيع إلكتروني (اعتماد) داخل المنصة، رفض (يُغلق الطلب نهائيًا)، أو طلب تعديل (يعود لصاحب الطلب).

| رمز AC | معيار القبول |
| --- | --- |
| AC-1 | عند اكتمال التوقيع الداخلي بالكامل (J-10)، يجد المتقدم الاتفاقية ضمن "إدارة الطلبات" ببوابة المدرب *(US-0215)* |
| AC-2 | يمكن للمتقدم معاينة الاتفاقية أو تحميلها بالكامل قبل اتخاذ قراره — تظهر له كل بياناتها دون استثناء |
| AC-3 | عند اختيار المتقدم التوقيع، يوقّع الاتفاقية إلكترونيًا **داخل المنصة** — بنفس آلية التوقيع الإلكتروني بـJ-10 — وتتحوَّل حالته تلقائيًا إلى "معتمد" |
| AC-4 | عند اختيار المتقدم الرفض، تُغلق حالة الطلب **نهائيًا** — لا مسار عودة أو إعادة تقديم تلقائي من هذي النقطة |
| AC-5 | عند اختيار المتقدم طلب تعديل، تُكتب ملاحظة تعود لصاحب الطلب (الشخص الذي أعدَّ الاتفاقية بـJ-10) |
| AC-6 | عند استلام صاحب الطلب لملاحظة التعديل، يعدّل الاتفاقية ويرفعها من جديد |
| AC-7 | عند إعادة رفع الاتفاقية المعدَّلة، تأخذ **سير توقيع داخلي جديد بالكامل من الصفر** (J-10) — لا استئناف من نقطة سابقة، لأنه مستند مختلف يحتاج اعتمادًا جديدًا |

**F2. توليد المستند النهائي والتسليم**
الوصف: بمجرد توقيع المتقدم إلكترونيًا، يُولَّد ملف PDF نهائي موقَّع تلقائيًا، تصبح الاتفاقية نشطة ضمن إدارة دورة حياة الاتفاقيات، وتُحفظ نسخة ببوابة المدرب نفسه.

| رمز AC | معيار القبول |
| --- | --- |
| AC-1 | عند توقيع المتقدم إلكترونيًا، يُولَّد تلقائيًا ملف PDF نهائي موقَّع (يحمل كل التواقيع الداخلية + توقيع المتقدم)، ويُحفظ مرتبطًا بملف المدرب *(BR-0221)* |
| AC-2 | عند اكتمال التوقيع، تنتقل الاتفاقية لـ CAP-03 (إدارة الاتفاقيات والعقود) كاتفاقية نشطة *(BR-0214)* |
| AC-3 | عند وجود الاتفاقية النهائية الموقَّعة، تُحفظ نسخة منها أيضًا ضمن **قسم الاتفاقيات ببوابة المدرب نفسه** — لا تبقى محفوظة فقط بالنظام الداخلي؛ يستطيع المدرب الوصول لها من ملفه بأي وقت |

---

### قواعد العمل (من BRD)

BR-0214 (الاتفاقية تصبح نشطة ضمن CAP-03 عند التوقيع) · BR-0221 (توليد PDF نهائي موقَّع تلقائيًا، مرتبط بملف المدرب)

### قواعد موضّحة بناءً على توضيحك (جديدة، مسجَّلة للمرجعية)

١. المتقدم له ثلاثة قرارات محتملة على الاتفاقية النهائية: توقيع، رفض (نهائي)، أو طلب تعديل.
٢. رفض المتقدم يُغلق الطلب نهائيًا، بلا مسار عودة.
٣. طلب تعديل المتقدم يعود لصاحب الطلب؛ بعد التعديل، تأخذ الاتفاقية سير توقيع داخلي جديد بالكامل (J-10 من الصفر) — لا استئناف، لأنه مستند مختلف يحتاج اعتمادًا جديدًا.
٤. الاتفاقية النهائية تُحفظ بمكانين: النظام الداخلي (مرتبطة بملف المدرب)، وقسم الاتفاقيات ببوابة المدرب.

### تمييز يستحق التوضيح

هذا يعيد فتح خيار الرفض/التعديل عند المتقدم رغم إننا ثبّتنا بـJ-09/J-10 مبدأ "لا رفض بعد الاعتماد النهائي للجنة". هذا **ليس تعارضًا**: قرارات J-09/J-10 تخص **أهلية الشخص نفسه** (محسومة مسبقًا). أما رفض/تعديل المتقدم بـJ-11 فهو قراره بشأن **بنود التعاقد نفسها** (السعر، الشروط، إلخ) اللي يشوفها كاملة لأول مرة بهذي المرحلة. هذا التمييز يستحق توثيحه صراحة حتى ما يُقرأ كتعارض قواعد من فريق التطوير.

---

### نقاط مفتوحة

١. **سبب/ملاحظة الرفض**: هل رفض المتقدم يتطلب سببًا (زي قائمة أسباب الرفض الموحّدة)، أو إجراء بسيط دون تبرير؟ لم يُحسم بعد.
٢. **مهلة عدم الاستجابة (SLA)**: محفوظة للتنظيف لاحقًا عند بناء مصفوفة المهل الشاملة، وفق طلبك.

جاهزين لـ J-12.
