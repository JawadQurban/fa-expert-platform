# Arabic Version

## الرحلة J-10 — إعداد الاتفاقية واعتمادها الداخلي

**الواجهة:** اللوحة الداخلية

---

### نطاق الرحلة

تبدأ من اكتمال الشرطين معًا من J-09: الاعتماد النهائي للجنة، واكتمال البيانات البنكية للمتقدم. تغطي إعداد الاتفاقية، تشكيل صاحب الطلب لسير التوقيع الداخلي (بنفس آلية تشكيل لجنة J-09 هيكليًا)، ومراجعة/توقيع كل شخص بالسير بالتسلسل. تنتهي باكتمال السير بالكامل **و**إرفاق التوقيع الإلكتروني من الشخص/الأشخاص المخصَّصين له معًا — حينها تُرسل الاتفاقية الموقَّعة تلقائيًا للمتقدم (J-11).

### رحلة المستخدم

١. عند اكتمال الاعتماد النهائي والبيانات البنكية معًا، يستلم صاحب الطلب تنبيهًا لإعداد الاتفاقية
٢. يُدخل الحقول القابلة للتعديل، وتُدمج بيانات المدرب الأساسية والبنكية تلقائيًا
٣. يشكّل صاحب الطلب سير التوقيع الداخلي — يحدد الأشخاص، يرتب تسلسلهم، ويحدد من هو المخصَّص فعليًا للتوقيع الإلكتروني
٤. المستند يصل لكل شخص بالسير حسب دوره؛ يمكنه معاينة الاتفاقية أو تحميلها بالكامل
٥. الشخص غير المخصَّص للتوقيع: يوافق أو يطلب تعديل — الموافقة تنقل الطلب تلقائيًا للتالي
٦. الشخص المخصَّص للتوقيع: يوقّع إلكترونيًا ويعتمد، أو يطلب تعديل
٧. تُرسل الاتفاقية الموقَّعة تلقائيًا للمتقدم فقط عند اكتمال السير بالكامل **و**إرفاق التوقيع الإلكتروني معًا — لا يكفي التوقيع وحده

---

### الخصائص الرئيسية والوظائف

**F1. إعداد الاتفاقية**
الوصف: صاحب الطلب يُعِدّ الاتفاقية التفصيلية بإدخال الحقول القابلة للتعديل أولًا، ثم دمج تلقائي لبيانات المدرب الأساسية والبنكية.

| رمز AC | معيار القبول |
| --- | --- |
| AC-1 | عند اكتمال الاعتماد النهائي (J-09) واكتمال البيانات البنكية للمتقدم معًا، يستلم صاحب الطلب تنبيهًا لإعداد الاتفاقية *(US-0211)* |
| AC-2 | يبدأ الإعداد بإدخال صاحب الطلب للحقول القابلة للتعديل، ثم تُدمج بيانات المدرب الأساسية والبنكية تلقائيًا بعد ذلك — دون إعادة إدخالها يدويًا *(BR-0212، موضَّحة)* |
| AC-3 | بناءً على نتيجة المقابلة التي حددت الخدمة/الخدمات المعتمدة، تعكس الاتفاقية بالضبط تلك الخدمات المعتمدة — لا أكثر ولا أقل *(US-0212)* |

**F2. تشكيل سير التوقيع الداخلي**
الوصف: صاحب الطلب يشكّل سير التوقيع بنفس آلية تشكيل لجنة الاعتماد (J-09/F2) هيكليًا — أشخاص، ترتيب، إلزامي/اختياري، قوالب محفوظة — مع تحديد من هو المخصَّص للتوقيع الإلكتروني الفعلي.

| رمز AC | معيار القبول |
| --- | --- |
| AC-1 | عند إعداد الاتفاقية، يشكّل صاحب الطلب سير التوقيع الداخلي — يحدد الأشخاص ويرتب تسلسل مراجعتهم |
| AC-2 | يُطبَّق نفس آليات J-09/F2 بالضبط: تصنيف كل شخص إلزامي/اختياري، وإمكانية حفظ السير كقالب مسمّى قابل لإعادة الاستخدام والتعديل |
| AC-3 | **توضيح صريح**: سير التوقيع هنا كيان منفصل عن لجنة اعتماد J-09 — الأول يراجع/يوقّع مستند الاتفاقية النهائي، والثاني يقرر مصير الطلب نفسه؛ لا يُخلط بينهما رغم تطابق الآلية الهيكلية |
| AC-4 | عند تشكيل السير، يُحدِّد صاحب الطلب أي شخص/أشخاص بالسير **مخصَّصون للتوقيع الإلكتروني** |
| AC-5 | عند اكتمال التشكيل، يُوجَّه المستند تلقائيًا لأول شخص بالسير |

**F3. معاينة الاتفاقية والموافقة/التوقيع**
الوصف: كل شخص بالسير يعاين أو يحمّل الاتفاقية بالكامل، ثم يتخذ قراره حسب دوره — موافقة عادية، أو توقيع إلكتروني فعلي إذا كان مخصَّصًا لذلك.

| رمز AC | معيار القبول |
| --- | --- |
| AC-1 | عند وصول دور الشخص بالسير، يستلم تنبيهًا بأن اتفاقية بانتظار مراجعته |
| AC-2 | يمكنه معاينة الاتفاقية أو تحميلها بالكامل — تظهر له كل بيانات الاتفاقية دون استثناء |
| AC-3 | عند وصول الدور لشخص **غير مخصَّص للتوقيع**، تظهر له خيارات: موافقة أو طلب تعديل — دون خيار توقيع إلكتروني؛ الموافقة تنقل الطلب تلقائيًا للشخص التالي بالسير |
| AC-4 | عند وصول الدور لشخص **مخصَّص للتوقيع**، تظهر له خيارات: توقيع إلكتروني واعتماد، أو طلب تعديل؛ يُرفق توقيعه على مستند الاتفاقية عند الاعتماد |
| AC-5 | تُرسل الاتفاقية الموقَّعة تلقائيًا للمتقدم فقط عند اكتمال **الشرطين معًا**: موافقة/مراجعة كل الأشخاص بالسير بالكامل (AC-3)، **و**إرفاق التوقيع الإلكتروني من الشخص/الأشخاص المخصَّصين له (AC-4) — لا يكفي التوقيع وحده إذا بقي أشخاص آخرون بالسير لم يوافقوا بعد *(BR-0213، موضَّحة)* |
| AC-6 | لا يوجد خيار "رفض" بهذا السير لأي شخص — الطلب معتمد نهائيًا أصلًا من J-09؛ الخيار الوحيد البديل عن الموافقة/التوقيع هو طلب تعديل (F4) |

**F4. طلب تعديل**
الوصف: أي شخص بالسير يمكنه طلب تعديل بدل الموافقة/التوقيع، بملاحظة إلزامية مرئية للجميع.

| رمز AC | معيار القبول |
| --- | --- |
| AC-1 | يحق لأي شخص بالسير طلب تعديل بدل الموافقة أو التوقيع، بملاحظة إلزامية تظهر لكل الأشخاص بالسير — بنفس نمط J-09/F7 |
| AC-2 | صاحب الطلب يستلم الملاحظة، يصحّح الاتفاقية، ويعيد عرضها |
| AC-3 | عند إعادة العرض، يستأنف السير من نفس الشخص الطالب للتعديل، دون التأثير على من سبقه |
