# Criterion #3 — «المجال» relevance classification

Every value of the approved 147-item domain list, each awaiting one binary
business decision: is this domain **related to the Financial Academy's work**?

`RELATED` → 10.00 points · `NOT_RELATED` → 0.00 points.

The classification is **COMMON** — identical for Trainer, Consultant, Content
Developer and Question Writer. It does not vary by service.

⚠️ Nothing here is inferred. A value stays OUT of the scoring table until it is
decided, and an applicant who picks an undecided value is reported as
**UNRESOLVED** rather than quietly scored 0 — a missing decision must never read
as a decided «ليس له صلة».

**To answer:** mark the last column, or simply reply with the numbers/codes that
are `RELATED` — the rest are then recorded as `NOT_RELATED` on your instruction.
The same list is fillable at `practical-experience-relevance.xlsx` (column E,
نعم / لا dropdown).
